# ShipFlow AI

ShipFlow AI is an AI-powered cross-border logistics
orchestration platform.

The project is being built as a learning-first project
to understand:

- Go backend development
- PostgreSQL
- Redis
- Kafka
- WebSockets
- distributed systems
- route optimization
- AI/RAG systems
- system design
- production engineering

The goal is not simply to build the application.

The goal is to understand how every major part of the
system works.
